#Bnb Booking Website

##About this project

This is a simple Bnb booking websitethat allows customers to view available houses and book accomodations online

#Features

-View available houses.
-Check house details.
-Book accommodation
-Contact us
-Admin dashboard
-View booking confirmations


#Technologies used

-HTML
-CSS
-JAVASCRIPT


#How To Run the Project

1.Download or clone the project
2.Open the project in VS.code
3.Open index.html
4.Right-click and select Open with live server
